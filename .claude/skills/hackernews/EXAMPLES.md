# Hacker News Skill 使用示例

## 快速开始

### 示例 1: 基础使用
抓取并分析一个热门帖子：

**输入：**
```
hackernews 38471822
```

**效果：**
- 获取帖子完整内容
- 获取所有评论
- 使用默认分析框架进行综合分析

## 实际应用场景

## 提示词模板

### 通用模板
```
hackernews <HN_ID> <分析角度> + <输出格式> + <特殊要求>
```

### 具体示例
```
hackernews 38471822 从初学者角度 + 用简单语言 + 包含学习路径
```

```
hackernews 38471822 从企业应用角度 + 列表格式 + 标注优先级
```

```
hackernews 38471822 技术深度分析 + Markdown + 包含代码示例
```

## 组合技巧

### 先概览后深入
```
1. hackernews 38471822 先给出 3 句话的总结
2. [看完总结后] 现在详细分析评论中的技术实现细节
```

### 对比分析
```
1. hackernews 111111 总结方案 A 的讨论
2. hackernews 222222 总结方案 B 的讨论
3. 对比这两个方案的优劣
```

---

## Tips

1. **明确目标**：清楚说明你想要什么样的分析
2. **指定角度**：从特定视角（技术、产品、业务等）分析
3. **限定范围**：如果评论很多，可以要求关注最高分评论
4. **输出格式**：指定你想要的输出格式（列表、表格、思维导图等）
5. **迭代优化**：先快速浏览，再根据需要深入特定部分

---

## 常见 HN 帖子类型

- **Show HN**: 项目展示，关注反馈和建议
- **Ask HN**: 问题讨论，关注解决方案
- **技术文章**: 深度分析，关注技术细节和替代方案
- **行业新闻**: 趋势分析，关注影响和预测
- **招聘帖**: 职位信息，关注要求和文化

根据帖子类型调整分析重点！
