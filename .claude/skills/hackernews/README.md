# Hacker News Analyzer Skill

这是一个用于 Claude Code 的自定义技能，可以抓取 Hacker News 帖子及其所有评论，并根据自定义提示进行深度分析。

## 功能特性

- 📖 抓取完整的 HN 帖子内容
- 💬 递归获取所有评论（包括嵌套回复）
- 🔍 支持自定义分析提示
- 📝 智能格式化和内容解析
- 🌳 保留评论层级结构

## 使用方法

### 基础用法

在 Claude Code 中输入：

```
hackernews <HN_ID>
```

例如：
```
hackernews 38471822
```

### 带自定义提示的用法

```
hackernews <HN_ID> <你的分析需求>
```

例如：
```
hackernews 38471822 请总结这个帖子中关于 AI 安全的讨论要点
```

```
hackernews 12345678 提取所有提到的技术栈和工具
```

```
hackernews 87654321 分析评论中的不同观点，并列出主要争议点
```

## 工作原理

1. **参数解析**：从用户消息中提取 HN_ID 和自定义提示
2. **内容抓取**：使用 HN API 获取帖子和所有评论
3. **内容存储**：将内容保存到临时文件（`/tmp/hn_<ID>.txt`）
4. **智能分析**：根据自定义提示或默认分析框架处理内容
5. **结构化输出**：以清晰的 Markdown 格式呈现分析结果

## 默认分析维度

如果不提供自定义提示，skill 会自动分析以下维度：

1. **帖子摘要**：主题和核心内容
2. **关键洞察**：最有价值的评论
3. **多元视角**：不同观点和立场
4. **技术细节**：提到的技术实现、工具、方法
5. **资源汇总**：链接、论文、工具等
6. **争议话题**：辩论和分歧点

## 技术实现

### 文件结构

```
.claude/skills/hackernews/
├── skill.md           # Skill 主配置文件
├── fetch_hn.js        # HN 内容抓取脚本
└── README.md          # 使用文档（本文件）
```

### API 使用

使用 Hacker News 官方 Firebase API：
- 端点：`https://hacker-news.firebaseio.com/v0/`
- 文档：https://github.com/HackerNews/API

### 数据处理

- HTML 实体解码
- 评论层级保留
- 已删除/死亡内容过滤
- 时间戳转换

## 依赖项

- Node.js（内置模块：https, fs, path）
- 无需额外 npm 包

## 注意事项

- HN API 无速率限制，但请合理使用
- 大型讨论（1000+ 评论）可能需要较长时间
- 已删除的评论会被自动跳过
- 输出文件临时保存在 `/tmp` 目录

## 故障排查

### HN_ID 无效
确保提供的是有效的 Hacker News 帖子 ID（纯数字）

### 抓取失败
检查网络连接，HN API 是否可访问

### 评论缺失
某些评论可能已被删除或标记为 dead
