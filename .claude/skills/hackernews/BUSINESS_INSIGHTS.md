## 🔧 高级技巧

### 技巧 1：组合多个查询获得全面视角

```
你：帮我全面了解 AI Agent 领域的情况，包括技术讨论、新项目和商业机会
```

Claude 会自动执行：
- AI 趋势查询（技术讨论）
- Show HN 查询（新项目）
- 创业机会查询（商业角度）
- 市场空白查询（需求分析）

### 技巧 2：使用时间范围控制信息新鲜度

- `1h`, `6h`, `12h` - 实时热点，适合紧急事件
- `24h`, `2d`, `3d` - 最新动态，适合每日摘要
- `7d`, `14d` - 周度趋势，适合深度研究
- `30d` - 月度回顾，适合全面分析

示例：
```
"过去24小时 AI 领域的热点" → --time 24h
"本周的创业想法" → --time 7d
"过去一个月的融资动态" → --time 30d
```

### 技巧 3：调整阈值控制内容质量

使用 `--min-points` 和 `--min-comments` 过滤低质量内容：

```
# 高质量深度内容
--min-points 50 --min-comments 30

# 平衡质量和数量
--min-points 20 --min-comments 10

# 发现新内容（降低阈值）
--min-points 5 --min-comments 3
```

### 技巧 4：自定义搜索挖掘特定话题

当预设查询不能满足需求时，使用自定义搜索：

```bash
# 搜索 Rust 相关的 Web 框架讨论
--query "Rust web framework" --min-points 15

# 搜索关于技术招聘的讨论
--query "hiring engineers" --tags ask_hn --min-comments 20

# 搜索远程工作的薪资讨论
--query "remote work salary" --time 30d --min-points 30
```

### 技巧 5：定期运行建立信息流

建立每日/每周的信息获取习惯：

**每天早上（5分钟）**：
```
"今天有什么重要的科技新闻？"
→ 获取每日摘要
```

**每周一（15分钟）**：
```
"过去一周 AI 领域有什么新趋势？"
"本周有什么好的创业想法？"
→ 获取周度深度分析
```

**每月总结（30分钟）**：
```
"过去一个月的 AI 投资动态"
"本月市场上有什么新需求？"
→ 获取月度趋势报告
```

## 🎯 最佳实践

### 1. 明确你的目标

❌ 不好：
```
"帮我看看 HN"
```

✅ 好：
```
"我想找 AI 领域的创业机会，特别关注 LLM 应用"
```

### 2. 利用时间范围

根据你的需求选择合适的时间范围：
- **发现新趋势**：1-3天
- **分析热点**：7天
- **深度研究**：14-30天

### 3. 迭代优化搜索

如果第一次搜索结果不理想：
- 调整关键词
- 改变时间范围
- 修改评分/评论阈值
- 尝试不同的预设

### 4. 交叉验证

对重要的发现，使用多个角度验证：
- 看 AI 趋势 + Show HN 项目
- 看创业想法 + 融资动态
- 看市场空白 + 用户讨论

### 5. 定期回顾

保存重要的发现，定期回顾：
- 某个需求是否仍然存在？
- 是否有新的解决方案出现？
- 机会窗口是否还在？

## 🚨 注意事项

1. **API 限制**：虽然 Algolia 没有明确的速率限制，但请不要过度频繁调用

2. **数据时效性**：HN 数据更新有延迟，最新内容可能需要几分钟才能被索引

3. **内容质量**：评分和评论数是质量指标，但不是唯一标准，需要自己判断

4. **隐私和版权**：HN 内容遵循其服务条款，商业使用请注意

5. **分析局限**：工具提供数据和趋势，但商业决策还需要你的判断和验证
