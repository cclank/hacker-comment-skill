# Hacker News Analyzer Skill for Claude Code

🔍 一个强大的 Claude Code 自定义技能，用于深度分析 Hacker News 帖子和评论

## ✨ 特性

### 核心功能
- 📖 **完整内容抓取**：获取 HN 帖子的完整内容和所有评论
- 💬 **递归评论**：支持多层嵌套的评论结构
- 🎯 **自定义分析**：使用自定义提示词进行针对性分析
- 🧠 **智能解析**：自动解码 HTML、格式化内容
- 📊 **热门内容**：获取 Top/New/Best/Ask/Show/Job 故事列表
- 🔍 **智能过滤**：按关键词或类别过滤内容
- 🏷️ **自动分类**：AI/ML、编程、Web、数据库、安全等
- 🌐 **中文输出**：所有内容使用中文展示，包含完整链接和统计信息

### 🎯 商业洞察功能（NEW!）
基于 Algolia API 的强大搜索和分析能力：
- 🤖 **AI 趋势发现**：追踪最新 AI 技术和应用
- 🚀 **创业机会**：发现商业机会和市场需求
- 💰 **融资动态**：跟踪投资和收购信息
- 🎯 **市场空白**：识别未被满足的需求
- 💵 **变现策略**：学习成功的商业模式
- 🌅 **每日摘要**：快速了解重要科技新闻
- 🔎 **高级搜索**：按时间、评分、评论数精确过滤
- 📈 **趋势分析**：自动生成热度统计和洞察报告

### 技术特点
- 🚀 **零依赖**：仅使用 Node.js 内置模块
- ⚡ **高效获取**：智能过滤和排序，快速获得价值信息
- 📊 **深度分析**：自动生成商业洞察和趋势报告
- 🎨 **美观输出**：使用 Emoji 和格式化增强可读性

## 🚀 快速开始

### 安装

1. 克隆或复制此 skill 到你的 Claude Code 配置目录：

```bash
# 如果你还没有 skills 目录
mkdir -p ~/.claude/skills

# 复制此 skill
cp -r .claude/skills/hackernews ~/.claude/skills/
```

2. 确保 Node.js 已安装：

```bash
node --version
```

### 使用

在 Claude Code 中直接输入：

```
hackernews <HN_ID>
```

或带自定义提示：

```
hackernews <HN_ID> <你的分析需求>
```

## 🔧 工作原理

### 基础模式（单帖和列表）
1. **参数解析**：从用户消息中提取 HN 帖子 ID 和分析需求
2. **内容抓取**：调用 HN Firebase API 递归获取帖子和所有评论
3. **内容存储**：将格式化的内容保存到临时文件（中文输出）
4. **AI 分析**：Claude 读取内容并根据提示进行分析
5. **结果展示**：以结构化的 Markdown 格式输出分析结果

### 商业洞察模式（Algolia API）
1. **意图识别**：识别用户的商业需求（AI趋势、创业机会等）
2. **查询构建**：根据预设或自定义构建 Algolia API 查询
3. **高级搜索**：使用 Algolia API 进行高效搜索和过滤
4. **数据分析**：自动计算热度统计、时间分布、内容类型等
5. **洞察生成**：生成最值得关注、讨论最激烈等推荐
6. **报告输出**：完整的中文商业洞察报告

## 🛠️ 技术栈

- **语言**：Node.js (JavaScript)
- **API**：Hacker News Firebase API
- **依赖**：无（仅使用内置模块：https, fs, path）

## 📊 API 说明

使用官方 Hacker News API：
- 基础 URL：`https://hacker-news.firebaseio.com/v0/`
- 文档：https://github.com/HackerNews/API

支持的 API 端点：
- `/item/<id>.json` - 获取帖子或评论详情

## ⚙️ 配置选项

### 输出模式

**直接输出模式（推荐）**：
- Skill 自动使用 `--direct` 标志
- 内容直接输出到 stdout，无需文件
- 更快、更实时、无缓存问题

**文件模式（兼容）**：
- 内容保存到 `/tmp/hn_<ID>_<timestamp>.txt`
- 文件名包含时间戳，保证每次都是新数据
- 适合超长内容或需要保存副本的场景

用户无需关心这些技术细节，Skill 会自动选择最佳模式。

## 🐛 故障排查

### 问题：HN_ID 无效
**解决**：确保提供的是有效的数字 ID，可以在 HN URL 中找到
```
https://news.ycombinator.com/item?id=38471822
                                    ^^^^^^^^ 这就是 HN_ID
```

### 问题：抓取失败
**解决**：
1. 检查网络连接
2. 确认 HN API 可访问
3. 检查 Node.js 是否正确安装

### 问题：内容不完整
**原因**：某些评论可能已被删除或标记为 dead
**说明**：这是正常现象，脚本会自动跳过这些评论
